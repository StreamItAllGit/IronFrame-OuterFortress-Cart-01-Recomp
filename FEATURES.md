## Capability Details (`v0.1.0` Baseline)

### Clean-Room Lift Recipes & 2-Member Cartridge Module
- **What it does:** Translates read-only decompilation metadata (`499` function seeds across `8` `UNROM` banks, `jumpTables: ["0xC6B7"]` with `0` hardcoded retail ROM addresses, `$C932..$C958` & `$FFD0..$FFD7` trampolines, and `$0200`/`$0300`/`$0380` memory watches) into a deterministic `9,167 B` 2-member `.recomp` package compiled asynchronously into `<dataDir>\cache\` by `reCart v0.1.3`'s `ColdAotCacheCompiler` + `LifterJumpTableScanner` (lifting `$C2BD -> JSR $C6B7 -> $C2C6/$C2F5` cleanly from user media).
- **Component:** `IronFrameCart01.RecipeGen` + `IronFrameCart01.Module`
- **Verification:** `RecipeGenTests`, `Cart01ModuleAndPackTests`, & `PrelaunchRegressionTests` (deterministic 499-seed emission, clean-room `$C6B7` inline jump-table lifting, read-only SoA `$0200/$0300/$0380` watch sampling, 2-member archive & local AOT compile round-trip, `20,002`-step differential lockstep `mismatchedSteps=0`, zero retail asset leaks)

### Multi-Format BYO Cartridge Verification (`NES-ME-USA`)
- **What it does:** Checks player-supplied dumps in `data\rom\` (`.nes`, headerless `.prg`, `.zip`, and `.7z` via `MediaContainerExtractor` + bundled `tools\7z.*` with ephemeral temp cleanup) against both `131,088`-byte headered `.nes` and `131,072`-byte headerless `.prg` SHA-256 checksums (`CartPrgHeaderSynthesizer` in-memory wrapping), failing closed on corruption and emitting 3-part remediation guidance when missing.
- **Component:** `IronFrameCart01.Module` (`ByoRomValidator`, `Cart01Constants`)
- **Verification:** Synthetic `.nes`/`.prg`/`.7z` validation, corrupt archive warning/cleanup paths, missing-ROM graceful diagnostics

### Clean-Root Launcher, Pre-Flight `.7z` Discovery & `DualSetup8` Installer
- **What it does:** Resolves compatible `reCart v0.1.3+` / `reEngine v0.6.2+` (deterministic precedence: `--reengine-dir` -> `--suite-dir` -> bundled -> persisted/registry), executes pre-flight BYO ROM discovery via [`LauncherMediaDiscovery`](Dev/src/IronFrameCart01.Launcher/LauncherMediaDiscovery.cs) (scanning `<dataDir>\rom\` and SHA-256-matched suite trees across `.nes`, `.prg`, `.zip`, and `.7z` using `ResolveSevenZipOverridePath` + `MediaContainerExtractor`, or passing `--preload-media` to open the Clean-Room Media Gate when absent), opens the SDL3 window immediately with live AOT compile overlay progress, `0 px` jitter `F3` HUD, persisted `F1` Video/Audio settings (`HostSettingsStore`), and reliable menu input, enforces `APP_ISOLATED_TEST=1` & 4-drive sandbox containment, seeds split-domain `settings*.json` files once without overwriting user preferences, enforces Release `--automation-port` `ExitCode = 2`, installs into coded `StreamItAll\reEngine\games\IronFrame-OuterFortress-Cart-01\` without double `reEngine` nesting, auto-discovers verified adjacent `Portable.zip` bundles for Online Setup, and preserves `data\rom\` and settings with `AllowAutoStart = false`.
- **Component:** `IronFrameCart01.Launcher` (`LauncherMediaDiscovery`) + `IronFrameCart01.Installer`
- **Verification:** `LauncherContainmentAndPrecedenceTests`, `InstallerPillar4AndOnlineHttpTests`, & `PrelaunchRegressionTests` (`50/50` total unit tests, `/warnaserror`; `audit_installer.ps1` `Passed: True, FindingCount: 0`), plus Stage 2 4-drive Sandbox E2E (`[S2-00]`..`[S2-09]`: Offline `Full` & Online Wizard UI automation, adjacent Portable auto-discovery, clean default install, `[S2-06]` Missing-ROM Media Gate `2.68s` + Demo Cart + corrupt `.7z` warning, `[S2-07]` Cold `.7z` AOT boot `4.21s` + `.zip`/`.prg`/`.nes` format matrix + `Enter` gameplay progression past title screen + `F3` HUD `w=623px` `0 px` jitter + WAV `peakPcm=16286` + `F5`/`F9` save, `[S2-08]` persisted `F1` `Scale=4x`/`VSync=true`/`Master Volume 70%` across quit/relaunch, `[S2-09]` standalone raw-ROM `.recomp` guard `2.18s`, HTTP `200`/`404`/tamper checks, silent upgrade preservation)
